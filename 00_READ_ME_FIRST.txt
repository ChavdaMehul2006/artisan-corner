⚠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Can't start MongoDB?
  → Download: https://www.mongodb.com/try/download/community
  → Or: Check Services app (services.msc)

Port 5000 or 5173 in use?
  → Edit server/.env: PORT=5001
  → Or: Kill Node processes: Get-Process -Name node | Stop-Process

Missing modules?
  → Run: npm run install-all

CORS or connection errors?
  → Check server/.env has: CLIENT_URL=http://localhost:5173

For detailed help:
  → See: SETUP_GUIDE.md (Troubleshooting section)
  → Or: SETUP_CHECKLIST.md (Troubleshooting checklist)
