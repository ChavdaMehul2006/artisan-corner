⚠️ COMMON ISSUES
════════════════════════════════════════════════════════════════════════════

MongoDB won't start?
  → net start MongoDB
  → Or: mongod --dbpath [path]
  → Check: Services app (services.msc)

Port 5000 in use?
  → Edit server/.env: PORT=5001
  → Or: Get-Process -Name node | Stop-Process

Can't find modules?
  → npm run install-all

CORS error?
  → Check CLIENT_URL in server/.env
  → Should be: http://localhost:5173

Page shows "Cannot find /"?
  → Already fixed! Root route now returns health check

For detailed troubleshooting:
  → See SETUP_GUIDE.md or SETUP_CHECKLIST.md
